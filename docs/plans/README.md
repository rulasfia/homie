# homie — plans

This directory holds short design notes for upcoming features. Each file is a
standalone proposal: goal, approach, open questions, and a rough implementation
sketch.

When a plan is approved, move it to a feature branch or remove it from here and
track progress in the commit messages.

## Plans

- [bookmark-favicons](bookmark-favicons.md) — auto-fetch site icons or fallback to letter avatars
- [custom-bookmark-icons](custom-bookmark-icons.md) — richer icon config (local assets, brand slugs, colors)
- [remote-docker-beszel](remote-docker-beszel.md) — container lists from every machine via Beszel
- [polish-and-mobile](polish-and-mobile.md) — transitions, empty states, responsive tweaks
- [deployment](deployment.md) — multi-arch image, compose, optional TLS/traefik labels
- [rss-feeds](rss-feeds.md) — balanced RSS/Atom headlines with bounded, demand-driven caching
